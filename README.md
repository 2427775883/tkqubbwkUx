# Python图书管理系统系统

## 核心功能
- 登录注册
- 图书推荐
- 图书借阅
- 图书数据可视化大屏
- 图书收藏
- 图书管理
- 借阅管理
- 用户管理
- 作者管理
- 分类管理
- 出版社管理
- 审计管理
- 公告管理

## 适用场景
- 图书馆
- 学校图书馆
- 个人图书馆管理

## 技术特点
- 使用Flask框架构建，具备良好的扩展性和稳定性
- MySQL数据库存储，确保数据的安全性和可靠性
- 前端使用Vue.js，界面友好，交互便捷
